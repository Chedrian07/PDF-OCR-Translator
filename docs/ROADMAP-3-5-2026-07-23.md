## 다음 구현 배치

1. 독립 equation 블록용 벡터 조판 PoC를 별도 모듈로 만들고, 원본 수식 보존을
   실패 폴백으로 둔다. 기존 `pdf_export.py`에 렌더러를 직접 섞지 않는다.
2. 실제 학술 PDF 코퍼스를 표 유형(무선/유선/병합 셀), 수식 유형, 세로쓰기,
   다단 레이아웃으로 분류해 golden 이미지와 bbox 교차 검사를 추가한다.
3. 다축 재배치는 자동 저장 전에 미리보기 리포트와 충돌 목록을 제공하고, 사용자
   승인 없이 원문 블록 순서를 바꾸지 않는다.
4. NVIDIA 장비가 준비되면 `check_cuda_environment.py` → `ocr-cuda` smoke → 동일
   PDF 코퍼스 순서로 실행하며 Metal 결과와 OCR 품질·처리 시간·VRAM을 비교한다.

모든 단계의 불변식은 같다. 조판 신뢰도가 부족하면 해당 블록의 원문을 보존하고,
페이지·이미지·벡터 그래픽은 외부로 전송하거나 손상시키지 않는다.
